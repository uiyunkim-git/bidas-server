# The Depression Collection

RNA-Seq data from: prefrontal cortex, cingulate cortex.

Access to this bucket requires an access key issued by KAIST-BISL.
See https://bidas.kaist.ac.kr/manual.html for the download guide.

    mc ls --recursive bidas/depression-collection/
    mc cp --recursive bidas/depression-collection/rna-seq/ ./download/
