# The Array Collection

RNA-Seq data from: cingulate cortex, choroid plexus, hippocampus.

Access to this bucket requires an access key issued by KAIST-BISL.
See https://bidas.kaist.ac.kr/manual.html for the download guide.

    mc ls --recursive bidas/array-collection/
    mc cp --recursive bidas/array-collection/rna-seq/ ./download/
