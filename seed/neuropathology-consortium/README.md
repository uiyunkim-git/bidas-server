# The Neuropathology Consortium

RNA-Seq data from: prefrontal cortex, orbitofrontal cortex, hippocampus.

Access to this bucket requires an access key issued by KAIST-BISL.
See https://bidas.kaist.ac.kr/manual.html for the download guide.

    mc ls --recursive bidas/neuropathology-consortium/
    mc cp --recursive bidas/neuropathology-consortium/rna-seq/ ./download/
